# Инструмент визуализации графа зависимостей

Практическая работа № 2, вариант 8, этап 1.

Приложение на C++17 принимает параметры командной строки, проверяет их
и выводит в формате `ключ=значение`. Загрузка зависимостей и построение
графа предусмотрены на следующих этапах.

## Сборка и тесты

Нужны компилятор C++17 и CMake. В Windows подойдёт Visual Studio
с компонентами разработки на C++. Команды выполняются из папки проекта.

Сборка:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

Сборка и запуск тестов:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -RunTests
```

Для запуска используется `run.bat` с нужными параметрами.
Справка: `.\run.bat --help`.

Пример запуска:

```powershell
.\run.bat --package express --version 4.18.2
```

## Параметры

| Опция | Назначение | По умолчанию |
| --- | --- | --- |
| `--package` | Имя пакета | Обязательно |
| `--repository` | URL реестра или путь к тестовому файлу | `https://registry.npmjs.org` |
| `--test-mode` | Режим тестового репозитория | Выключен |
| `--version` | Точная версия пакета в формате SemVer | Обязательно |
| `--output` | Имя будущего SVG-файла | `graph.svg` |
| `--ascii` | Режим ASCII-дерева | Выключен |
| `--filter` | Подстрока для исключения пакетов | Пустая строка |

В тестовом режиме имена пакетов задаются заглавными латинскими буквами,
а репозиторий — существующим непустым файлом. Флаги `--test-mode` и `--ascii`
не принимают значений. При ошибке программа выводит причину и возвращает код `2`.
